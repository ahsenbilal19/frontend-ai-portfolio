## 📖 About the Project

This repository contains my **capstone project** for the **FlyRank Frontend AI Engineering Internship**. It is a modern, AI-integrated portfolio website built to showcase frontend engineering skills, clean architecture, and thoughtful user experiences.

The goal of this project is to demonstrate:

- Proficiency in **React** and **Next.js** (App Router, SSR, ISR)
- Type-safe development with **TypeScript**
- Utility-first, responsive styling with **Tailwind CSS**
- Integration of **AI-powered features** into a real-world web application
- Clean, maintainable, and beginner-friendly code practices

## 🚀 Getting Started

### Prerequisites

- **Node.js** v18+ (recommended: v20 LTS)
- **npm**, **yarn**, or **pnpm**

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/frontend-ai-portfolio.git

# Navigate into the project directory
cd frontend-ai-portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at [http://localhost:3000](http://localhost:3000).
